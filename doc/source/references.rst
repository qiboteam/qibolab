References
==========

For an overview of the project's architecture and its role in the Qibo
ecosystem, see the `Qibolab paper <https://arxiv.org/abs/2308.06313>`_.
Software releases are also archived on
`Zenodo <https://doi.org/10.5281/zenodo.10572987>`_. Follow the
`Qibo citation policy
<https://qibo.science/qibo/stable/appendix/citing-qibo.html>`_ when citing
Qibolab in a publication.

The textbook below provides background on quantum information. It is a
conceptual reference, not a specification of Qibolab's current API; use the
guides and API reference in this documentation for package behavior.
